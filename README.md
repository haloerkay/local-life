**项目简介：**仿大众点评的本地生活服务平台，围绕高并发场景优惠券秒杀与热点查询提供端到端的解决方案。

**技术栈：** Java 17、Spring Boot、MySQL、Redis、Lua、Kafka、Caffeine、MyBatis-Plus等。 

**主要工作** 

- **全链路流控：**基于授权令牌 + 令牌桶实现一次性访问与限流，设计 IP + 用户双维度全链路流控体系，并结合分 级惩罚机制，在库存预扣前拦截无效请求，显著降低秒杀接口瞬时洪峰压力。 
- **多层缓存体系：**构建券详情 Caffeine 本地 + Redis 双层缓存，结合布隆过滤器、空值缓存、双重检测和互斥锁 机制，解决优惠券查询中的缓存穿透、缓存击穿问题。单机 100 线程三轮压测，QPS 约5.1k，P99 31ms。 
- **秒杀功能：**通过 Redis + Lua 脚本实现原子性扣减与一人一单校验，结合 Kafka 异步创建订单、MySQL 条件扣 减控制库存。连接预热后，1000用户抢200张券，200笔受理全部落库，无超卖、无重复有效订单。 
- **MQ可靠性保障：**对 Kafka 生产者和消费者进行抽象封装，消费端按唯一键幂等去重，统一处理“发送失败、消 费前超时、消费中异常、消费后处理”四类场景，形成可复用的可靠消息能力。 
- **全局唯一ID与全链路对账：** 采用雪花算法生成全局唯一订单ID；并结合traceId、对账日志等方式记录关键业务 操作，便于对秒杀过程中的异常场景进行排查、补偿与一致性追踪。
